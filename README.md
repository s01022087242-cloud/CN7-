# 사출성형 품질 분석 프로그램 UI

사출성형 공정 데이터를 확인하고 품질 예측 결과를 조회할 수 있도록 제작한 Python 데스크톱 UI입니다.

이 문서는 프로젝트 전체가 아니라 **Tkinter 기반 사용자 인터페이스 구현 범위**를 설명합니다. 데이터 전처리 규칙, 머신러닝 모델 학습 방식과 성능 개선은 별도의 분석 모듈에서 담당합니다.

## UI 구현 목적

- 사용자가 복잡한 Python 코드를 직접 실행하지 않고 CSV를 선택할 수 있도록 구성
- 데이터 확인부터 모델 평가와 개별 예측까지의 작업 순서를 화면으로 안내
- 영문 공정변수에 한국어 설명을 함께 표시해 가독성 개선
- 주요 기능을 탭으로 분리하여 원하는 화면으로 쉽게 이동할 수 있도록 구성

## 주요 화면

### 1. 왼쪽 제어 영역

- CSV 파일 선택
- 타깃 변수 확인
- 분류 모델 선택
  - Gradient Boosting
  - Random Forest
- 테스트 데이터 비율 선택
- 교차검증 횟수 선택
- 모델 학습 및 새 제품 예측 버튼

### 2. 데이터 입력

- 선택한 CSV의 행·열 크기 표시
- 데이터 앞부분 미리보기
- 열 너비 자동 조정 및 가로·세로 스크롤 지원

### 3. 전처리

- 결측값 개수 표시
- 중복 행 개수 표시
- 제외된 인덱스·상수 열 표시
- 양품과 불량의 건수 및 비율 표시
- 최종 독립변수 개수 표시

현재 사용하는 `project_data.csv`는 양품과 불량이 1:1로 구성되어 있으며, UI는 CSV에서 읽은 실제 분포를 동적으로 표시합니다.

### 4. 시각화(EDA)

- 양품·불량 분포 그래프
- 변수 간 상관관계 히트맵
- 선택 변수의 양품·불량 상자그림
- 주요 변수 간 산점도

### 5. 리터러시 Q&A

초보 사용자도 분석 결과를 이해할 수 있도록 미리 정의된 질문과 해석을 제공합니다.

- 불량과 관련성이 큰 변수
- 데이터에서 주의할 품질 문제
- Accuracy만으로 모델을 평가하면 안 되는 이유

### 6. 모델링 및 평가

- 사용 모델과 학습·평가 데이터 건수 표시
- 교차검증 F1-score 표시
- 주요 특성 중요도 표시
- Accuracy, Precision, Recall, F1-score, ROC-AUC 표시
- 혼동행렬과 특성 중요도 그래프 표시
- 불량으로 예측된 데이터를 텍스트 파일로 저장

### 7. 예측 결과

- 공정변수별 입력칸 자동 생성
- 입력값을 이용한 양품·불량 결과 표시
- 불량 확률 표시
- 숫자가 아닌 값 입력 시 오류 안내

## UI 구성 특징

- `ttk.Style`을 사용한 색상·글꼴·버튼 스타일 통일
- 화면 크기에 대응할 수 있는 프레임 기반 레이아웃
- 기능별 탭 구성
- 테이블과 입력 영역의 스크롤 지원
- 오류·경고·저장 완료 메시지박스 제공
- Matplotlib 그래프를 Tkinter 화면 내부에 표시
- 표준화된 공정값은 화면에서 소수점 셋째 자리까지 표시

## 실행 방법

### 1. 패키지 설치

PyCharm Terminal에서 다음 명령을 실행합니다.

```bash
pip install -r requirements.txt
```

### 2. 프로그램 실행

```bash
python main.py
```

### 3. 데이터 선택

프로그램 실행 후 왼쪽 상단의 **열기** 버튼을 눌러 `project_data.csv`를 선택합니다.

## UI 관련 파일

```text
main.py            프로그램 실행 및 Tkinter 메인 루프 시작
ui.py              화면 배치, 위젯, 그래프, 사용자 이벤트 처리
data_analyzer.py   UI가 호출하는 데이터 분석 기능
requirements.txt   실행에 필요한 Python 패키지
```

UI 구현의 중심 파일은 `ui.py`이며, 실제 분석 기능은 `DataAnalyzer` 객체를 통해 호출합니다. 이 구조를 사용해 화면 코드와 분석 코드를 분리했습니다.

## UI 작업 범위

이번 UI 작업에서 담당한 내용은 다음과 같습니다.

- 전체 화면 레이아웃 설계
- 사이드바와 단계별 탭 제작
- CSV 선택 및 데이터 미리보기 화면 제작
- 전처리 결과 표시 화면 제작
- EDA 그래프 표시 영역 제작
- 모델 선택과 학습 설정 입력 화면 제작
- 평가 지표·혼동행렬·특성 중요도 표시 화면 제작
- 한 건 예측 입력 및 결과 화면 제작
- 사용자 오류 안내와 상태 메시지 처리

다음 항목은 UI가 아니라 분석 로직의 범위입니다.

- 데이터 생성 및 클래스 비율 조정
- 결측값 처리 기준 결정
- 모델 하이퍼파라미터 최적화
- 모델 성능 검증 및 해석
- 실제 제조 공정 적용 여부 판단

## 사용 시 주의사항

- `PassOrFail`은 `0=양품`, `1=불량`으로 사용합니다.
- 현재 데이터의 공정변수는 전처리·표준화된 값이므로 실제 온도나 압력값과 단위가 다를 수 있습니다.
- UI에 표시되는 소수점 값은 가독성을 위해 반올림되지만, 내부 분석에는 원래 정밀도를 사용합니다.
- 예측 결과는 프로젝트 분석용이며 실제 현장의 품질검사를 대체하지 않습니다.

## 향후 UI 개선 계획

- 모델 학습 중 진행 상태 표시
- 학습 작업을 별도 스레드로 실행하여 화면 멈춤 방지
- 실제 공정 단위 입력과 표준화 자동 변환
- 입력 가능 범위를 벗어난 값에 대한 경고
- 그래프 이미지 저장 기능
- 모델별 평가 결과 비교 화면
